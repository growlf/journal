## Overview
This section documents the architectural roles and conceptual configurations of the various nodes in the NetYeti lab. Specific identifiers (IPs/MACs) are sanitized for public instruction.

## Primary Infrastructure
- [[Network/Devices/Core-Router|Core Router (Concept)]]: The perimeter edge and segmentation point.
- [[Network/Devices/Hypervisor|Hypervisor Host (Concept)]]: The compute and storage backbone.
- [[Network/Devices/House-Router|House Router (Concept)]]: Residential WiFi and IoT gateway.

## Learning Objectives
- Understanding the relationship between an Edge Router and a Hypervisor.
- Exploring physical vs logical segmentation in a home lab.
- Managing "Ghost Signals" and decommissioned assets via an archiving system.
