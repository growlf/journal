# BMS-DNS-01 (10.10.0.4)

The primary DNS and DHCP server for the makerspace.

## Software
- **OS:** Ubuntu 24.04 LTS
- **Application:** [[Knowledge Base/Networking/DNS/Technitium DNS & DHCP|Technitium]]

## Role
- **DHCP:** Serves the 10.10.0.0/16 pool for members and staff.
- **DNS:** Internal name resolution for `.bellinghammakerspace.org` and split-DNS for public services.
