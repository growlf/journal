# BMS-PVE-03 (10.10.0.8)

A Hewlett Packard Enterprise (HPE) server acting as a node in the BMS Proxmox cluster.

## Services
- **Proxmox VE (8006):** Hypervisor management.
- **SSH (22):** Remote management active.
- **DNS (53):** Active DNS listener. 

## Notes
- **Hardware:** ProLiant or similar HPE chassis (MAC `1C:98:EC`).
- **Role:** Potential backup server or virtualization host for BMS internal services.
