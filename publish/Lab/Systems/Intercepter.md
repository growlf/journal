# Secondary Storage System
This doodad is as odd as it is cool. It is literally a Raspberry Pi CM4 with 16 POE 1G ports (to run the Pi racks), 4 1G LAN/WAN ports and a 5+ bay drive system - all in a 1U shallow rack case. They used to be Axzez, now Exaviz. I have it loaded with 5x5TB 3.5 WD-Blacks, because there was a sale ;)
