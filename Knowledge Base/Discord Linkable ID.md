This is URL that can be used to consistently link to a specific user account in Discord.

## Getting the ID
Enable Developer Mode in your Discord settings and then right-clicking (or holding on mobile) on your username to copy your ID. The format for this link is typically  `https://discord.com/users/USERID`, where you replace `USERID` with your copied ID like so:
```http
https://discord.com/users/<your id goes here>
```
For example, [[Garth Johnson]]'s is https://discord.com/users/227141869962919936.
