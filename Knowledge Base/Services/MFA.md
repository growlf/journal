# Multi-Factor-Authentication
Multi-Factor Authentication (MFA) is a security process that requires users to provide two or more forms of verification to access an account, like a password combined with a code from a mobile app or a fingerprint scan. By requiring multiple verification factors, MFA adds layers of security to prevent unauthorized access even if one factor, like a password, is compromised. 
## How it works
- MFA combines at least two different types of evidence to verify a user's identity.
- These factors typically fall into three categories:
    - **Something you know:** A password or PIN.
    - **Something you have:** A physical object like a mobile phone (to receive a code via text or an authenticator app) or a hardware security key.
    - **Something you are:** A biometric identifier, such as a fingerprint or face scan.
- For example, a user might enter their password (something you know) and then be prompted to enter a one-time code sent to their phone (something you have) to log in. 

## Why it's used
- **Enhanced security:** MFA significantly reduces the risk of a successful cyberattack by making it much harder for attackers to gain unauthorized access.
- **Protection against compromised credentials:** Even if an attacker steals a username and password, they won't be able to access the account without the second or third authentication factor.
- **Broad application:** MFA is used to secure everything from online accounts like email and banking to physical access to buildings or computer networks.
